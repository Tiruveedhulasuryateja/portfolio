# Surya Teja Tiruveedhula — Portfolio

Personal portfolio website built with pure **HTML, CSS, and JavaScript** (no frameworks, no build step).

## Live Site

Once deployed: `https://<your-username>.github.io/portfolio/`

## Sections

- **Hero** — animated typing roles, terminal-style profile card
- **About** — experience highlights and animated stats
- **Skills** — programming, frameworks, databases, instrument control, data analysis, tools
- **Experience** — accordion timeline (Pinaka Aerospace, Astra Microwave, Advantum Health)
- **Projects** — selected defence & aerospace work
- **Education & Credentials** — VIT B.E. CSE-AI, certifications, honours
- **Contact** — email, phone, LinkedIn, and mailto-powered contact form

## Run Locally

Just open `index.html` in a browser, or serve it:

```bash
python -m http.server 8080
```

Then visit http://127.0.0.1:8080

## Structure

```
portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    └── resume.pdf
```

## Customization

- **Theme colors:** edit CSS variables in `:root` at the top of `style.css`
- **Content:** edit text directly in `index.html`
- **Resume:** replace `assets/resume.pdf` with an updated copy
